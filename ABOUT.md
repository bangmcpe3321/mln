# About This Project

## Vật Chất & Vận Động — Triết học Mác – Lênin

`mln` is an interactive Vietnamese-language web presentation that introduces key concepts from Marxist–Leninist philosophy, including matter, motion, rest, space, time, and the material unity of the world.

The project is designed as an engaging educational resource for classroom presentations, self-study, and reviewing lesson content through an accessible browser-based interface.

## Highlights

- Full-screen, responsive slide presentation.
- Interactive slide navigation with previous and next controls.
- Category-based navigation for major lesson sections.
- Automatic slide playback with pause and resume controls.
- Searchable lesson content.
- Bookmarks for saving important slides.
- Detailed slide content displayed in modal dialogs.
- Responsive layout for desktop and mobile devices.
- Reduced-motion support for users who prefer fewer animations.
- No framework, package manager, or build process required.

## Main Topics

- Historical views of matter.
- Lenin’s definition of matter.
- Forms and modes of existence of matter.
- Motion and rest.
- Space and time.
- The material unity of the world.
- The methodological meaning of the lesson.
- The dialectical relationship between quantity and quality.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- SVG graphics
- Google Fonts: Roboto and Oswald

## Repository Contents

- `index.html` — Main interactive presentation page.
- `styles.css` — Presentation styles and responsive layout rules.
- `script.js` — Browser interactions and educational demos.
- `assets/` — Images and other visual resources.
- `vat_chat_nhom1_slide.txt` — Matter and motion lesson notes.
- `slide_luong_chat.txt` — Quantity–quality law lesson notes.

## Intended Audience

This project is intended for students, educators, and anyone looking for a visual introduction to selected topics in Marxist–Leninist philosophy.

## Running the Project

The presentation can be opened directly by launching `index.html` in a modern browser. It can also be served locally with a simple HTTP server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
